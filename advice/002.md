继续，但我会先把“层级路由 = (\eta^\star\le0)”这一点撤掉。你这轮理论与实现本身有价值，尤其固定结构后仍保持 LP、强对偶和 DW/staleness 可继承；但 D0.92-A 的结果实际上暴露了一个新的理论边界，而不是证明了 `Pareto-improvement exhaustion` 可以直接替代任务判据。

### 1. `η*≤0` 作为主路由判据，在当前定义下数学上基本不会触发

你定义

[
D_q^0=\sum_i\frac{b_i}{Q}a_{iq}
]

本身对应一个可行的均匀功率分配 (p^0)。因此

[
r_q(p^0)=0,\quad\forall q,
]

所以 (\eta=0) 永远可行，从而

[
\boxed{\eta^\star\ge0.}
]

只有当 (D^0) 已经是某种 Pareto 边界点、完全不存在所有目标同时正比例改善时，才可能得到

[
\eta^\star=0.
]

而你现在已经实测

[
\eta^\star=0.3157>0,
]

但对应

[
worst=0.4456.
]

因此若采用“(\eta^\star>0) 就留在功率层”，8/8 会**明确拒绝升级结构层**，尽管最差目标仍然很弱。

所以：

[
\boxed{
\eta^\star
\text{ 是 bargaining value，不是 layer-sufficiency certificate。}
}
]

这是下一版理论必须分开的两个概念。

## 2. 这次实验也没有证明“任何单一标量目标都无法兼顾 worst 和 steady”

目前你证明的是两个点：

[
\text{max-min}:
(0.6363,;0.7460),
]

[
\text{bargaining}:
(0.4456,;0.8263),
]

这里括号表示 `(worst, steady)`。

它说明：

[
\boxed{\text{这两种 scalarization 选择了明显不同的 Pareto 方向。}}
]

但不能推出：

[
\nexists p:\ worst(p)\ge0.60,;steady(p)\ge0.80.

中间完全可能存在一个功率解，例如概念上：

[
(0.61,;0.81).
]

所以“两个端点一个过 worst、一个过 steady”其实更应该触发一个非常重要的新 Gate：

[
\boxed{\text{固定结构下的 Pareto 可行域究竟长什么样？}}
]

而不是马上换 routing。

这比继续设计第三个 scalar objective 更重要。

# 3. 真正应该抽象的是“可达性能集合”，而不是某一个标量值

我建议把理论再上升一层。

对于系统状态 (s)，定义三个层级的动作集合：

[
\mathcal U_P(s)
\subseteq
\mathcal U_S(s)
\subseteq
\mathcal U_G(s),
]

分别表示：

[
\text{power only},
\quad
\text{structure+power},
\quad
\text{geometry+structure+power}.
]

然后定义性能映射

# [ \mathbf y(u)

\begin{bmatrix}
J_1(u)\
\vdots\
J_M(u)
\end{bmatrix},
]

其中 (J_m) 可以是一般的 sensing task function，而不是固定绑定到 8/8 的三个数字。

于是每一层真正拥有的是一个**可达性能集合**

# [ \boxed{ \mathcal R_\ell(s)

{\mathbf y(u):u\in\mathcal U_\ell(s)}.
}
]

并且理论上应该满足

[
\mathcal R_P
\subseteq
\mathcal R_S
\subseteq
\mathcal R_G.
]

这才是三层架构最自然的数学对象。

你当前总纲已经明确把快层、结构层、几何层分别看成 LP、MILP 和连续非光滑优化，但目前还主要通过某个 scalar value 把它们连接起来。

下一步我认为应该改成：

[
\boxed{
\text{统一的是 achievable region，而不是强行统一 scalar objective。}
}
]

------

# 4. 然后把“任务需求”抽象成一个集合，而不是写死 0.6/0.7/0.8

定义一个任务可接受集合

# [ \boxed{ \mathcal A(\xi)

{
\mathbf y:
g_m(\mathbf y;\xi)\ge0,\quad m=1,\ldots,M
},
}
]

其中 (\xi) 是任务参数。

比如当前实验里的

[
worst\ge0.60,\quad
weak3\ge0.70,\quad
steady\ge0.80
]

只是某个具体实例

[
\xi=\xi_{\rm Medium}.
]

换一个任务以后：

[
\xi
]

可以变化，但理论、算法和三层架构都不变。

这样就解决了你之前指出的问题：

> 优化理论不能围绕某个 8/8 数字建立。

因为理论只说：

[
\mathcal R_\ell(s)
\cap
\mathcal A(\xi)
]

是否为空。

具体数字只是应用层配置。

------

# 5. 那么真正正确的层级路由是一个“可行性路由”

定义：

# [ F_\ell(s,\xi)

\begin{cases}
1,&
\mathcal R_\ell(s)\cap\mathcal A(\xi)\neq\emptyset,\
0,&
\text{otherwise}.
\end{cases}
]

路由逻辑变成：

[
\boxed{
\begin{aligned}
F_P=1
&\Rightarrow \text{只用快层};\
F_P=0,;F_S=1
&\Rightarrow \text{升级结构层};\
F_S=0,;F_G=1
&\Rightarrow \text{升级几何层}.
\end{aligned}}
]

这比：

[
\eta^\star\le0
]

强很多。

因为它直接回答：

> **这一层的控制自由度是否足以完成任务？**

而不是：

> 相对于一个人为 reference point，还能不能共同改善一点？

这也与当前总纲原本的“固定结构不足才进中层、同几何不足才进慢层”的架构精神一致。

# 6. bargaining 应该保留，但角色要改

我不建议废掉 D0.92。

相反，D0.92 给你的理论体系增加了一个很有用的**层内选择原则**。

以后把两个问题分开：

[
\boxed{
\text{Routing: 当前层是否足够？}
}
]

和

[
\boxed{
\text{Allocation: 当前层内部选哪个 Pareto 点？}
}
]

前者由：

[
\mathcal R_\ell\cap\mathcal A
]

决定。

后者才使用 bargaining：

[
\max_p\min_q
\frac{D_q-D_q^0}{D_q^I-D_q^0}.
]

所以可以形成：

[
\boxed{
\text{Feasibility outside, Bargaining inside}.
}
]

这会比“所有东西都靠 bargaining value (V)”更加严谨。

# 7. 如果当前层可行，bargaining 还可以继续优化，而不是停在门槛

假如功率层存在

[
p:\mathbf y(p)\in\mathcal A,
]

那么不是找到一个刚刚达标的解就停止。

可以解：

[
\max_{p}\eta(p)
]

s.t.

[
\mathbf y(p)\in\mathcal A,
]

[
p\in\mathcal P.
]

即：

> 任务约束只定义 admissible set，bargaining 继续在 admissible set 里尽可能提高资源公平利用率。

这里没有“针对 0.6/0.8 调 objective”。

如果换任务需求，只是 (\mathcal A) 改变。

这在通信系统里是非常正常的层次：

[
\boxed{
\text{QoS = constraint},
\qquad
\text{resource utility = objective}.
}
]

# 8. 如果完全不想使用任务门槛，则必须承认另一个基本数学事实

如果没有：

- QoS requirement；
- 通信/能量预算；
- 或高层 activation cost，

那么**不存在唯一合理的层级触发规则**。

因为假设结构层只比功率层提高

[
\Delta\eta=10^{-6},
]

但需要额外：

[
10\text{ kbit}
]

通信。

到底升不升级？

Pareto 理论本身无法回答。

同理，如果提升：

[
\Delta\eta=0.2
]

但结构切换带来 100 ms delay，到底值不值？

必须额外指定：

[
\text{performance requirement}
]

或者

[
\text{resource budget}.
]

这是基本的决策理论，不可能通过一个“纯数学、无参数 trigger”绕过去。

因此真正抽象的论文不是“没有参数”，而是：

[
\boxed{
\text{参数属于任务模型，而不是偷偷写进算法结构。}
}
]

# 9. 现在 D0.92 还有一个值得严格审计的地方：(D^0)

你当前：

# [ D_q^0

\sum_i\frac{b_i}{Q}a_{iq}
]

数学上当然合法：

- 可行；
- 对目标置换对称；
- 不依赖未来；
- 易于计算。

所以 T1 作为**feasible reference** 没问题。

但如果把它称为 bargaining 的 `disagreement point`，还需要更谨慎。

经典 bargaining 中 disagreement point 更接近：

> 协商失败时各方真正能保证得到的 fallback outcome。

而“均匀分功率”只是一个人为选定的 reference policy。

这两者不是一回事。

并且你的结果：

[
steady\uparrow,\qquad worst\downarrow
]

很可能部分来自这个 reference 的选择，而不仅仅是 bargaining 原理。

因此下一轮建议补一个非常重要的理论/数值 Gate：

[
\boxed{\text{Reference Sensitivity Audit}}
]

只需要比较少数**有理论意义**的 reference：

- uniform feasible allocation；
- noncooperative/local-only fallback；
- previous committed allocation。

而不是扫描几十种 (D^0)。

检查：

[
\eta^\star,
\quad
\mathbf D^\star,
\quad
\lambda^\star
]

对 reference 是否剧烈变化。

如果结论对 (D^0) 很敏感，那么不能宣称：

> bargaining 天然解决了 steady 张力。

只能说：

> 当前 reference-normalized bargaining 倾向于提高总体效率。

这个表述更严格。

# 10. (D^I) 也需要保持“同一可行域”这一纪律

你现在写：

[
D_q^I=\sum_i b_i a_{iq}
]

只有在以下条件同时成立时才确实是 individual ideal point：

[
p_{iq}=b_i,\quad p_{ir}=0,\ r\neq q
]

必须满足当前**完整固定结构可行域**。

如果还有：

- per-target capacity；
- TX/RX role 限制；
- owner 限制；
- 单 UAV 某些 target 不可服务；

则这些限制必须已经体现在 (a_{iq}=0) 或 feasible set 中。

否则 (D^I) 会成为 optimistic ideal，而不是同域 ideal。

这点最好加入 T1 的假设，而不是只放代码逻辑里。

## 12. 这一步对创新性反而更有帮助

你现在的主线可以从：

[
\text{“一个 bargaining value 贯穿三层”}
]

升级为更严谨的：

[
\boxed{
\textbf{Capability-Region Certified Hierarchical ISAC Coordination}
}
]

核心逻辑是：

[
\text{Physical feasible set}
\rightarrow
\text{achievable sensing region}
\rightarrow
\text{task-feasibility certificate}
\rightarrow
\text{Pareto/bargaining allocation}
\rightarrow
\text{activate the minimum necessary control layer}.
]

然后：

- 快层：凸可达区域 / 强对偶；
- 中层：整数结构扩展可达区域 / integrality gap；
- 慢层：几何改变区域边界 / local directional sensitivity；
- 通信层：为进入更高层支付实际 bit / delay / energy；
- D0.88：继续负责 power solution 的 temporal staleness certificate。

这比“(\lambda+\mu)”或“(\eta\le0)”都更符合你要求的**基本数理常识 + 通感约束 + 理论抽象性 + 一定创新性**。

最关键的一步现在其实非常明确：**先别改 routing 代码，先对当前 8/8 fixed structure 求 `(worst, steady)` 的 Pareto frontier。** 如果 frontier 上已经存在同时高 worst、高 steady 的点，那么问题只是 D0.92 的 bargaining reference/scalarization 没选到；如果整个 frontier 都不存在这样的点，才有理论依据说“功率自由度耗尽，需要结构层”。
