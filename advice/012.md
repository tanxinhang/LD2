是，**从“对方能否发现我们”而不是“我们向外辐射了多少能量”出发，更合理，也更容易形成真正有理论意义的模型。**

单纯的电磁暴露约束

[
E_w\le \Gamma_w
]

本质只是一个**物理代理量**。同样的接收功率，对方如果拥有更大的阵列、更长的积累时间、更低的噪声、更准确的波形先验，其探测能力完全不同。低概率截获/隐蔽通信的经典建模也通常最终落在“warden 能否区分 (H_0) 与 (H_1)”上，而不是单纯限制发射功率。([arXiv](https://arxiv.org/abs/1202.6423?utm_source=chatgpt.com))

这实际上可以让我们前面刚刚精炼出来的理论模型再提升一次，而且不会重新发散。

# 1. 我更建议把“隐蔽性”定义成一个对抗检测问题

假设目标本身或者外部监听节点 (w) 具有探测能力。

它面对的是二元假设：

[
\begin{cases}
\mathcal H_0:&\text{UAV 未执行可识别的主动感知/传输},\
\mathcal H_1:&\text{UAV 正在执行主动 ISAC 感知/通信}.
\end{cases}
]

对方收到

[
y_w=
\begin{cases}
n_w, &\mathcal H_0,\
s_w(X,Z,P)+n_w, &\mathcal H_1.
\end{cases}
]

然后自己运行检测器：

[
T_w(y_w)
\underset{\mathcal H_0}{\overset{\mathcal H_1}{\gtrless}}
\eta_w.
]

于是我们真正关心的不再是

[
P_i\le P_{\max}^{\rm stealth}
]

或者

[
E_w\le\Gamma_w,
]

而是

# [ \boxed{ P_{D,w}^{\rm int}

\Pr(T_w>\eta_w|\mathcal H_1)
}
]

——即**对方发现我方活动的概率**。

这在概念上明显比“低辐射”更加准确。

# 2. 对你当前模型而言，最漂亮的方法是引入“对方 Deflection”

你现在自己的感知已经有：

[
D_q^{\rm sense}
\rightarrow
P_{D,q}^{\rm sense}.
]

因此完全可以构造一个**镜像检测问题**。

### 我方对目标的检测能力

# [ D_q^{L}

\sum_{i}
a_{iq}^{L}(X,Z)p_{iq}.
]

这里 (L) 表示 legitimate sensing。

最大化：

[
\min_qD_q^L.
]

### 对方对 UAV 辐射的探测能力

定义：

# [ \boxed{ D_w^{I}

\sum_{i,q}
a_{iwq}^{I}(X,Z),p_{iq}
}
]

其中 (I) 表示 intercept。

这里的

[
a_{iwq}^{I}
]

不是简单路径损耗，而是**对方探测器每瓦能够获得的检测信息**。

它应该包含：

# [ a_{iwq}^{I}

f(
L_{iw},
G_{iw},
G_w^{RX},
B_w,
NF_w,
N_w,
T_{{\rm int},w},
\chi_w,
\mathcal K_w
).
]

也就是：

- UAV → 对方的传播增益；
- UAV 朝对方方向的发射增益；
- 对方接收阵列增益；
- 对方噪声系数；
- 对方监听带宽；
- 天线数量；
- 积累时间；
- 信道条件；
- **对方对我方波形/时隙/载频的先验知识**。

这样“对方探测能力”正式进入模型。

# 3. 如果沿用当前 Deflection→(P_D) 抽象，模型会异常整齐

当前己方：

# [ P_{D,q}^L

Q\left(
Q^{-1}(P_{FA}^L)-\sqrt{D_q^L}
\right).
]

如果假定对方的检测统计量也满足同类 Gaussian-shift/Deflection 模型，则可以写：

# [ P_{D,w}^{I}

## Q\left( Q^{-1}(P_{FA,w}^{I})

\sqrt{D_w^{I}}
\right).
]

注意：这是**一个明确的建模假设**，不能对任意能量检测器、未知波形检测器都声称成立。

但它跟你当前系统非常匹配。

于是隐蔽要求直接变成：

[
\boxed{
P_{D,w}^{I}\le \epsilon_w.
}
]

甚至可以转换成 Deflection 硬约束：

[
D_w^{I}
\le
\bar D_w^{I},
]

其中

# [ \boxed{ \bar D_w^{I}

## \left[ Q^{-1}(P_{FA,w}^{I})

Q^{-1}(\epsilon_w)
\right]^2.
}
]

这就非常有意思了。

原来是：

[
\text{电磁功率}<\Gamma.
]

现在变成：

[
\boxed{
\text{敌方检测性能}<\epsilon.
}
]

物理意义强很多。

# 4. 这样，“距离”和“功率”都不需要人为单独设隐蔽限制了

这是最大优点之一。

原来我们考虑：

[
d_{iw}\ge d_{\rm stealth},
]

和

[
P_i\le P_{\rm stealth}.
]

其实有些人为。

现在它们自然通过：

[
D_w^I(X,P)
]

耦合起来。

例如简化情况下：

[
a_{iw}^{I}
\propto
\frac{
G_iG_wT_{{\rm int},w}
}{
d_{iw}^{2}\sigma_w^2
}.
]

那么：

[
D_w^I
\propto
\frac{P_iT_{{\rm int},w}}
{d_{iw}^{2}\sigma_w^2}.
]

约束

[
D_w^I\le\bar D_w
]

自然推出：

[
P_i
\lesssim
\bar D_w
\frac{d_{iw}^2\sigma_w^2}
{T_{{\rm int},w}}.
]

所以：

- 距离越近 → 允许功率越低；
- 对方积累时间越长 → 我方允许功率越低；
- 对方阵列越强 → 我方隐蔽性越难；
- 对方噪声越低 → 隐蔽性越难。

这才是真正体现**对面探测能力**的约束。

# 5. 我甚至建议不要只设一个固定“对方”

这会进一步提高理论质量。

因为现实中，我们未必准确知道对方拥有：

- 几根天线；
- 多大带宽；
- 多长积累；
- 多好的噪声系数；
- 是否知道我们的 OTFS 参数；
- 是否知道我们的发射时隙。

所以定义一个对方能力参数：

# [ \theta_w

(
G_w,
N_w,
NF_w,
B_w,
T_{{\rm int},w},
K_w,\ldots
).
]

并规定

[
\theta_w\in\Theta_w.
]

然后不是要求某一个理想化对方：

[
P_D^I(\theta_w)\le\epsilon,
]

而是：

[
\boxed{
\sup_{\theta_w\in\Theta_w}
P_D^I(X,Z,P;\theta_w)
\le\epsilon.
}
]

这就是：

[
\boxed{\textbf{Robust Counter-Detection Constraint}}
]

它回答的是：

> 在假设对方具有某一等级以内的最大探测能力时，我方仍然不容易被发现。

这个表述比“低暴露”高级很多。

# 6. 可以定义三个对方能力等级，实验也很好做

例如先不要把模型弄得过细，可以设计：

### Weak interceptor

- 小阵列；
- 短 CPI；
- 较高 NF；
- 不知道完整波形结构。

### Medium interceptor

拥有部分时频信息和中等积累能力。

### Strong interceptor

知道：

- (f_c)；
- OTFS frame timing；
- waveform family；
- 较准确的信道统计；

并且有大阵列、长积累。

于是最终性能曲线变成：

[
P_{D,\min}^{L}
\quad\text{vs}\quad
\text{opponent capability}.
]

这个比 sweep：

[
\Gamma_{\rm exposure}
]

具有更明确的含义。

# 7. 从严格理论上，还可以进一步升级到 Detection Error Probability

如果要叫真正的 **covert/LPD**，我建议以后不要只限制对方 (P_D)。

原因是，对方可以人为选择极低的 threshold：

[
P_D\rightarrow1,
]

但同时：

[
P_{FA}\rightarrow1.
]

显然这种“检测能力”并不强。

因此 covert communication 文献更常用：

# [ \boxed{ \xi_w

P_{FA,w}+P_{MD,w}
}
]

其中

[
P_{MD}=1-P_D.
]

对方会寻找最优阈值，使：

# [ \xi_w^\star

\min_{\eta}
(P_{FA}+P_{MD}).
]

而我方希望：

[
\boxed{
\xi_w^\star\ge1-\epsilon.
}
]

也就是说，即便对方使用最佳检测器，也很难区分 (H_0/H_1)。这种 detection-error formulation 是 covert communications 的标准思路之一。([arXiv](https://arxiv.org/abs/1202.6423?utm_source=chatgpt.com))

这比单独约束 (P_D) 更严谨。

# 8. 更理论化以后，可以直接用 KL divergence

定义对方观察在：

[
\mathcal H_0:\quad p_0(y_w),
]

[
\mathcal H_1:\quad p_1(y_w).
]

如果要求

[
\boxed{
D_{\rm KL}(p_0|p_1)
\le
2\epsilon^2,
}
]

则通过 Pinsker 类型界可以给对方最优二元检测错误提供 covertness 保证；这也是 covert communication 中常用的 tractable surrogate。([arXiv](https://arxiv.org/pdf/1807.00719?utm_source=chatgpt.com))

于是从理论强度上可以分三层：

[
\boxed{
\begin{array}{ccc}
\text{received exposure}
&
\rightarrow
&
\text{interceptor }P_D
\[1mm]
\text{简单代理}
&&
\text{检测性能}
\
&&\downarrow\
&&
\xi^\star=P_{FA}+P_{MD}
\
&&\downarrow\
&&
D_{\rm KL}(p_0|p_1)
\end{array}}
]

越往下越严格，但对信号统计模型要求也越高。

# 9. 对你当前项目，我不建议立即跳到 KL

这是很关键的取舍。

当前系统明确没有完整原始 IQ/OTFS waveform detection pipeline，而是 geometry-driven Deflection abstraction。

因此直接写：

[
D_{\rm KL}(p_0|p_1)
]

就必须回答：

[
p_0(y),p_1(y)
]

到底是什么。

包括：

- 对方观察了多少 OTFS symbols；
- 噪声分布；
- fading；
- 是否知道 data；
- 是否知道 pilot；
- 是否 coherent；
- 是否能够积累多个 UAV；
- UAV 间信号是否同步。

如果这些没有 waveform-level model 支持，KL 会变成“看起来理论很强、实际建立在空中”。

所以当前阶段最合理的是：

[
\boxed{
\textbf{Detection-Capability-Constrained Model}
}
]

而不是直接 full covert theory。

# 10. 这样最终母问题就可以非常漂亮

定义：

[
D_q^L(X,Z,P)
]

为我方感知 Deflection；

[
D_w^I(X,Z,P;\theta_w)
]

为对方截获/发现 Deflection。

最终：

[
\boxed{
\begin{aligned}
\max_{X,Z,P,t}\quad&t\
\text{s.t.}\quad
&D_q^L(X,Z,P)\ge t,
&&\forall q,\
&D_w^I(X,Z,P;\theta_w)
\le\bar D_w^I,
&&\forall w,\
&|x_i-x_j|\ge d_{\rm sep},
&&\forall i\ne j,\
&|x_i-y_q|\ge d_{\rm safe},
&&\forall i,q,\
&P_{{\rm comm},i}+\sum_qp_{iq}
\le P_i^{\max},\
&\text{U2U rate/latency/reliability constraints},\
&Z\in\mathcal Z,\quad X\in\mathcal X.
\end{aligned}}
\tag{DC-MM}
]

如果对方能力未知，则：

[
\boxed{
\sup_{\theta_w\in\Theta_w}
D_w^I(X,Z,P;\theta_w)
\le
\bar D_w^I.
}
]

我认为这就是一个非常有潜力的最终理论模型：

[
\boxed{
\textbf{Detection-Constrained Max-Min Distributed ISAC}
}
]

或者更准确一点：

[
\boxed{
\textbf{Counter-Detection-Aware Distributed UAV-ISAC}
}
]

# 11. 更漂亮的是：对偶价格现在具有“攻防”解释

之前：

[
\lambda_q
]

代表目标 (q) 的 sensing bottleneck。

现在给 counter-detection constraint 引入：

[
\mu_w\ge0.
]

inner LP 的局部资源价值就变成：

## [ \boxed{ \lambda_q a_{iq}^{L}

\mu_w a_{iwq}^{I}.
}
]

因此一个 UAV 是否应该给目标 (q) 加功率，不只取决于：

> 能给我方带来多少 sensing gain，

同时取决于：

> 会给对方带来多少 detectability gain。

也就是说每瓦功率真正的价值成为：

## [ \boxed{ \text{legitimate sensing gain}

\text{counter-detection cost}.
}
]

这比此前的：

[
\lambda a-\mu\times\text{received power}
]

理论意义更强，因为第二项已经从**能量成本**升级成了**对方检测性能成本**。

## 因此，我会正式修正上一轮建议

不要把“low electromagnetic exposure”作为最终核心创新。

它最多保留为一个 baseline：

[
\boxed{\text{Exposure-Constrained}}
]

新的主要方法应该是：

[
\boxed{
\textbf{Opponent-Detection-Constrained}
}
]

实验上可以做一个非常有说服力的比较：

1. **Power-constrained**：仅限制 Tx power；
2. **Exposure-constrained**：限制对方接收功率；
3. **Detection-constrained**：限制对方实际 (P_D/)Deflection；
4. 后续有波形模型以后，再增加 **KL/DEP-constrained**。

如果 1 和 2 在不同 opponent capability 下失效，而 3 始终控制

[
P_{D,w}^{I}\le\epsilon,
]

那就能够非常直接地证明：

> **为什么不能只看发射功率或电磁暴露，而必须建模对方的实际探测能力。**

我认为这比单纯增加安全距离或 exposure budget 又把理论往前推进了一层，而且仍然能和你现有的 **max-min + dual price + distributed coordination** 主线很好地统一。
