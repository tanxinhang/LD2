对，这个问题比前面“0.60/0.70/0.80 不该进入目标函数”更根本：

> **不能让优化问题随着某一次 8/8 仿真的结果不断改写。**

否则即使每一步数值都提升了，最后论文也容易变成“围绕当前实验调出来的一套控制器”，理论抽象性不足。当前总纲已经有 LP—MILP—几何三层和 gap certificate 的雏形，但“完整对偶 (\lambda+\mu)”仍带有较强的针对当前 worst/steady 冲突补丁色彩。

我建议继续往上抽象一层：**不再把 worst、weak3、steady 本身作为优化函数，而把它们降为评价指标；优化层建立在“多目标感知信息如何公平且高效地共享有限通感资源”这一更一般的问题上。**

------

# 一、重新确定理论问题：优化的不是某几个 (P_D) 数字，而是“多目标感知信息分配”

固定一个控制周期，目标 (q) 得到的有效统计信息记为

[
D_q=\sum_i a_{iq}p_{iq},
]

其中：

- (a_{iq})：当前结构和几何下每瓦感知信息效率；
- (p_{iq})：UAV (i) 给目标 (q) 的感知功率；
- (D_q)：Deflection，直接刻画 (H_0/H_1) 的统计可分性。

对于固定 (P_{\rm FA})，

[
P_{D,q}=g_q(D_q)
]

单调增加，因此优化 (D_q) 在检测理论上有明确意义，而且避免直接依赖某一段 (P_D(D)) 的曲率。

于是问题抽象成：

[
\boxed{
\text{有限通信—感知资源下，如何分配 }D_1,\ldots,D_Q
\text{，兼顾公平性与效率？}
}
]

这对：

- (K=4,Q=4)；
- (K=8,Q=8)；
- (K\ne Q)；
- 不同目标位置；
- 不同信道；
- 不同 QoS 门限

都成立。

这才适合作为论文的核心数学问题。

------

# 二、不要直接再选一个 weighted sum；可以用“公理化公平”来定义目标

如果写：

[
\max \alpha,worst+\beta,steady+\gamma,weak3,
]

本质仍然是：

> 为什么是这些权重？

很难回答。

更理论化的方法是先规定系统效用应该满足什么**基本公理**。

设

[
\Phi(D_1,\ldots,D_Q)
]

是系统感知效用，我们至少希望：

### A1. 单调性

[
D_q'\ge D_q,\ \forall q
\Longrightarrow
\Phi(\mathbf D')\ge\Phi(\mathbf D).
]

任何目标的信息增加都不能让系统变差。

### A2. 边际收益递减

[
\frac{\partial^2\Phi}{\partial D_q^2}\le0.
]

一个已经很好检测的目标继续加功率，价值应逐渐下降。

这正好避免旧

[
-\log(1-P_D)
]

的“富者愈富”。

### A3. 目标置换不变

对于同优先级目标：

[
\Phi(P\mathbf D)=\Phi(\mathbf D)
]

对任何目标置换矩阵 (P)。

这与你现有的 permutation-equivariant architecture 是一致的。

### A4. 公平性 / Schur-concavity

如果两组 (\mathbf D) 总信息相同，但一组更均衡，那么：

[
\mathbf D^{(1)}
\prec
\mathbf D^{(2)}
\quad\Longrightarrow\quad
\Phi(\mathbf D^{(1)})
\ge
\Phi(\mathbf D^{(2)}).
]

也就是：

> 不允许只靠把资源堆在几个强目标上制造高平均性能。

这四条比任何 `0.6/0.7/0.8` 都更像论文理论基础。

------

# 三、进一步：我建议用“Bargaining”而不是再发明一个 utility

这里有一个非常适合当前系统，而且比普通 max-min 更一般的理论框架：

[
\boxed{\text{Kalai-Smorodinsky / Bargaining-based sensing allocation}}
]

它恰好解决我们最近碰到的问题。

对每个目标定义两个抽象量：

### 1. disagreement/reference point

[
D_q^{0}
]

表示**不依赖额外协同优化时，系统对目标 (q) 已经保证的基准信息**。

它可以来源于：

- local-only；
- 当前已承诺 allocation；
- 上一控制周期保证值；
- 非合作工作点。

注意它不是 `0.6`。

它是**系统状态的一部分**。

------

### 2. ideal point

# [ D_q^{I}

\max_{p\in\mathcal F}D_q(p).
]

即：

> 在相同物理资源、相同结构下，如果只服务目标 (q)，它最多能够拿到多少信息。

它也是由当前物理模型推出来的，而不是人为给定。

于是定义归一化感知增益：

# [ r_q(p)

\frac{
D_q(p)-D_q^0
}{
D_q^I-D_q^0
}.
]

这里：

[
r_q=0
]

表示没有超过基本保障；

[
r_q=1
]

表示目标 (q) 已经拿到了自身理论上全部可用 headroom。

------

# 四、然后主优化问题变得非常干净

求：

[
\boxed{
\max_{p,\eta}\quad\eta
}
]

满足

[
D_q(p)
\ge
D_q^0+\eta(D_q^I-D_q^0),
\qquad\forall q,
]

以及真实通感约束：

[
\sum_qp_{iq}=P_i^{\rm tot}-P_i^{\rm comm},
]

[
p_{iq}\ge0.
]

如果存在结构约束，再加入对应可行集。

这不是：

[
\max\min_qD_q.
]

而是：

[
\boxed{
\max\min_q
\frac{D_q-D_q^0}
{D_q^I-D_q^0}.
}
]

物理解释特别清楚：

> **让每个目标都尽可能获得相同比例的“可实现感知提升机会”。**

------

# 五、这个目标比 pure max-min 高一个层次

传统 max-min：

[
\max\min_qD_q
]

默认所有目标的：

- 基础条件相同；
- 几何难度相同；
- 可达上限相同。

实际 UAV-ISAC 显然不是这样。

例如：

[
D_1^I=100,\qquad D_2^I=10.
]

如果最终：

[
D_1=10,\qquad D_2=10,
]

传统 max-min 会认为非常公平。

但实际上：

[
r_1=10%,
\qquad
r_2=100%.
]

目标 1 只获得了自己潜力的 10%。

反过来，若：

[
D_1=50,\qquad D_2=5,
]

则：

[
r_1=r_2=50%.
]

从“机会公平”看反而更合理。

这和 UAV 不同几何条件、不同双基地增益天然匹配。

------

# 六、它还有一个很强的数学优点：固定结构下仍然是 LP

因为：

[
D_q(p)=\sum_i a_{iq}p_{iq}
]

是线性的。

所以

## [ \sum_i a_{iq}p_{iq}

\eta(D_q^I-D_q^0)
\ge D_q^0
]

也是线性的。

因此固定 structure：

[
\boxed{\text{仍是标准 LP}}
]

意味着你已经做好的：

- 强对偶；
- Dantzig–Wolfe；
- staleness；
- 量化 price；
- event trigger

几乎全部可以继承。

这点非常关键。

我们不是为了换一个理论故事把 D0.87/D0.88 推倒重来。

而是：

[
\boxed{\text{把 max-min LP 升级成 normalized bargaining LP}.}
]

------

# 七、而且新的 dual price 比现在的 (\lambda+\mu) 更自然

对约束

[
D_q
\ge
D_q^0+\eta h_q,
\qquad
h_q=D_q^I-D_q^0,
]

定义对偶变量

[
\lambda_q\ge0.
]

那么 Lagrangian 对 (\eta) 的 stationarity 会给出类似：

[
\boxed{
\sum_q\lambda_qh_q=1.
}
]

于是目标价格不再只是：

> 谁现在最弱？

而是：

> **哪个目标的单位“未恢复 headroom”对整个 bargaining optimum 最稀缺？**

这比现在：

[
\lambda^*+\mu^*
]

更干净。

当前总纲中“(\mu) 用来抵消 (\lambda)”实际上已经带有补丁性质；D0.89-B 的负结果也说明单纯 hard-(\lambda) 会过度集中最差目标。

新的 (\lambda_q) 是从一个统一 primal 中自然产生的，不需要人为再补一个 counterbalance。

------

# 八、steady / weak3 / worst 怎么处理？

全部降级成：

[
\boxed{\text{evaluation metrics}}
]

而不是 foundational objective。

也就是说优化器永远求：

[
\eta^\star
]

和对应

[
\mathbf D^\star.
]

仿真之后再算：

[
P_D^{worst},
\quad
P_D^{bottom-k},
\quad
P_D^{avg}.
]

具体某个任务要求：

[
P_D^{worst}\ge\rho_w,
]

[
P_D^{tail}\ge\rho_t,
]

[
P_D^{avg}\ge\rho_a,
]

只用于：

### 1. 系统验收；

### 2. 快层→中层→慢层的 escalation；

而不是改变优化器本身。

这样换一个应用场景，即使要求从：

[
(0.6,0.7,0.8)
]

变成别的数字，

**核心优化算法完全不用改。**

这就是你说的“抽象层”。

------

# 九、通信侧也应该做同样的抽象化

现在 bit、delay、1 W 都是真实物理量。

但不要再写：

[
\max \Phi-\beta_B B-\beta_TT.
]

因为又会出现：

> (\beta_B,\beta_T) 为什么这么取？

更合理的是**词典序优化**。

### 第一层

先最大化 sensing bargaining value：

# [ \eta^\star

\max_{\mathcal F_{\rm phy}}\eta.
]

其中 (\mathcal F_{\rm phy}) 已经包含：

- 1 W 总功率；
- (P_{\rm comm}+P_{\rm sense}=P_{\rm tot})；
- half-duplex；
- U2U capacity；
- packet delivery；
- deadline；
- role/owner；
- DD support。

### 第二层

在保证

[
\eta\ge\eta^\star-\epsilon
]

的情况下：

[
\boxed{
\min C_{\rm comm}
}
]

其中通信资源可以根据论文重点定义成：

[
E_{\rm comm},
\quad
\text{airtime},
\quad
\text{bits}
]

中的一个**物理资源量**。

这不是 weighted sum。

它表达的是：

> **首先保证感知最优，然后在不显著损伤感知的前提下使用最少通信资源。**

和 ISAC 的基本原则更一致。

------

# 十、这样整个三层都可以用同一个抽象 value function

定义：

# [ \boxed{ V(x,S,c)

\max_{p}
\min_q
\frac{
D_q(p;x,S,c)-D_q^0
}{
D_q^I-D_q^0
}
}
]

其中：

- (x)：UAV geometry；
- (S)：role / owner / sensing structure；
- (c)：communication state/resource；
- (p)：快层 sensing power。

于是：

## 快层

[
V(x,S,c)
]

在固定 (x,S,c) 下是 LP。

**精确求解。**

------

## 中层

[
\max_S V(x,S,c)
]

是 mixed-integer optimization。

**LP relaxation → upper bound；**

**feasible structure → lower bound；**

定义：

# [ G_S

V_{\rm relax}-V_{\rm feasible}.
]

这才是真正的 structure gap。

总纲目前已经有类似“非凸性的价格”框架，这部分可以直接继承，但建议以后统一围绕同一个 (V)，而不是不同层各用不同目标。

------

## 慢层

[
\max_x V(x,S,c).
]

DD 支撑不变且局部 active basis 稳定时，可以使用 Danskin：

# [ \nabla_xV

\sum_q\lambda_q^\star
\sum_i
p_{iq}^\star
\nabla_xa_{iq}
]

——更准确地说，如果 (D^0,D^I) 在一个 trust region 内冻结，这是相应参数化 LP 值函数的局部方向信息。

然后：

# [ x^{+}

\Pi_{\mathcal X}
\left[
x+\alpha d
\right].
]

且满足：

[
|\Delta x_i|
\le v_{\max}\Delta t.
]

遇到：

[
g_{dd}=g_{\min}
]

跨门：

[
\boxed{\text{停止局部微分模型，重新锚定 LP。}}
]

这正好继承 D0.88 已经发现的 DD 支撑不连续事实。

# 十一、还有一个很重要的理论细节：(D^0,D^I) 不能随便定义

如果走这条路线，我建议下一轮首先研究这个，而不是直接写代码。

### (D_q^0)

应该是可保证的 disagreement point，例如：

[
D_q^0=
D_q^{\rm local/noncooperative}
]

或者 epoch 开始时已经承诺的感知水平。

它必须：

- 可计算；
- 可实现；
- 不依赖未来 oracle；
- 对目标置换保持一致。

------

### (D_q^I)

必须来自**相同物理可行域**：

# [ D_q^I

\max_{p\in\mathcal F_{\rm same}}
D_q(p).
]

不能拿 relaxed oracle。

否则归一化分母就把不存在的能力算进去了。

这一点非常重要。

------

# 十二、如果发现“不可能同时改善所有目标”，也不要修模型

这一点反而可以成为理论结果。

若：

[
\eta^\star\le0,
]

说明：

> 在当前固定 structure / geometry / communication 下，不存在相对于 disagreement point 的严格 Pareto improvement。

那么就**自然触发中层**：

[
S\rightarrow S'.
]

若结构层仍有：

[
\eta^\star\le0,
]

再触发 geometry。

所以三层路由甚至不必完全依赖：

[
0.6/0.7/0.8.
]

可以有一个更理论化的路由依据：

[
\boxed{\text{Pareto-improvement exhaustion}}
]

这比“没过某个数字所以换层”更一般。
