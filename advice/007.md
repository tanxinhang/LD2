## 1. L3 的核心问题建议正式改成

固定一个 geometry decision epoch，先保持结构 (S) 不变，定义

[
\boxed{
\min_{x\in\mathcal X}
\gamma^\star(x;S)
}
]

其中内部问题仍然是：

# [ \gamma^\star(x;S)

\min_{\gamma,p}\gamma
]

满足完整任务 QoS、真实感知功率预算以及当前通信条件。

物理意义非常直接：

[
\gamma^\star=1.20
]

表示当前几何下需要约 20% 的等效额外 sensing budget 才能完成任务。

因此 UAV 移动真正应该追求的是

[
\boxed{
\gamma^\star(x+\Delta x)<\gamma^\star(x),
}
]

最终希望进入

[
\gamma^\star\le1.
]

这样 L0/L1/L2/L3 的语言就完全统一了：

[
\text{不是谁把 }P_D\text{ 做得最大，}
]

而是：

[
\boxed{\text{哪个控制自由度能够消除 task capability deficit。}}
]

# 2. 不要直接复用旧公式 (\lambda p\nabla a)

这是 L3 最需要尊重数理常识的一点。

旧 max-min LP 下有类似

[
\nabla_x t^\star
\sim
\sum_{iq}\lambda_q^\star
p_{iq}^\star
\nabla_x a_{iq}.
]

但你现在真正的 primal 已经不是 simple max-min，而包含：

- worst；
- bottom-(k)；
- steady；
- sensing budget scaling (\gamma)。

因此 L3 应从**当前 capability primal 的 KKT 条件重新推导**。

设一般任务约束写成

[
F_m(\mathbf D)\ge\rho_m,
]

或者标准形式

# [ c_m(\mathbf D)

\rho_m-F_m(\mathbf D)
\le0.
]

设其最优对偶变量为

[
\alpha_m^\star\ge0.
]

功率预算：

[
\sum_qp_{iq}-\gamma b_i(x)\le0
]

的对偶为

[
\beta_i^\star\ge0.
]

而

# [ D_q(x,p)

\sum_i a_{iq}(x)p_{iq}.
]

定义真正的 target sensitivity price：

# [ \boxed{ \pi_q^\star

# -\sum_m \alpha_m^\star \frac{\partial c_m}{\partial D_q}

\sum_m
\alpha_m^\star
\frac{\partial F_m}{\partial D_q}
\ge0.
}
]

那么在 regular、active set 不变的局部区域，由 envelope/KKT sensitivity 得到

# [ \boxed{ \frac{\partial\gamma^\star} {\partial a_{iq}}

-\pi_q^\star p_{iq}^\star.
}
]

这才是现在应该使用的“价格”。

不是旧的：

[
\lambda_q^\star.
]

# 3. 几何梯度因此应该是

如果暂时把 sensing budget (b_i) 固定，那么：

# [ \boxed{ \nabla_{x_k}\gamma^\star

- 

\sum_{i,q}
\pi_q^\star
p_{iq}^\star
\nabla_{x_k}a_{iq}.
}
]

但这里还有一个 ISAC 非常重要的项。

如果 UAV 移动以后通信链路也变化，从而

[
P_{{\rm comm},i}^{\min}=P_{{\rm comm},i}^{\min}(x),
]

那么：

# [ b_i(x)

1-P_{{\rm comm},i}^{\min}(x).
]

此时完整梯度应该还有：

# [ \boxed{ \nabla_{x_k}\gamma^\star

- 

## \sum_{iq} \pi_q^\star p_{iq}^\star \nabla_{x_k}a_{iq}

\gamma^\star
\sum_i
\beta_i^\star
\nabla_{x_k}b_i.
}
]

第二项非常有意义：

[
\underbrace{\nabla a}*{\text{sensing geometry}}
+
\underbrace{\nabla b}*{\text{communication geometry}}.
]

也就是说：

> UAV 往某个目标飞近可能改善 sensing，却可能拉远 U2U peer、增加通信功率，反而减少 sensing budget。

这才是真正的 ISAC 几何优化，而不是单纯“朝目标飞”。

当前系统明确是 U2U 通信与感知共享严格 `1 W` 预算，因此这个耦合项物理上不能长期忽略。

第一版 L3 可以先冻结 (b)，做 **sensing-only sensitivity audit**；但正式版本最终应该包含这个通信项。

# 4. 双基地结构还意味着一个 UAV 会通过两个身份影响梯度

你的

[
a_{iq}
]

实际是固定 owner 后的

[
a_{i,j_q,q}.
]

所以 UAV (k) 移动时：

[
\nabla_{x_k}a_{i,j_q,q}
]

不仅在

[
k=i
]

时非零；

当

[
k=j_q
]

即该 UAV 是接收 owner 时，也非零。

因此正式实现不能只写：

```text

    gradient += ...
```

必须把：

[
\boxed{
\text{Tx geometry effect}
+
\text{Rx/owner geometry effect}
}
]

都加进去。

这对双基地 UAV-ISAC 是基本物理要求。

# 5. DD 门仍然是绝对边界：不要跨门求梯度

当前每瓦有效增益包含

[
\mathbf1[g_{dd}\ge g_{\min}],
]

所以：

[
g_{dd}=g_{\min}
]

附近 (a(x)) 发生支撑改变。

这时：

[
\nabla_xa
]

不能继续作为普通局部微分对象。当前系统文档也已经明确把 DD support discontinuity 列为几何层理论边界。

因此 trust region 必须满足：

[
\boxed{
\text{当前预测步内不跨 DD support boundary}.
}
]

若检测到可能跨门：

[
\boxed{
\text{DD crossing event}
\Rightarrow
\text{重新计算 support + capability problem}
}
]

而不是让 gradient 穿过去。

# 6. “熵正则化 λ”这里我建议再谨慎一点

你说：

> 配熵正则化处理 (\lambda^\star) 退化。

可以做，但**不能把正则化后的价格继续称为原问题的精确梯度**。

因为如果 optimal dual 不唯一，

[
\gamma^\star(x)
]

本身可能不可微，只存在一组 subgradient / directional derivative。

更严格的路线是：

[
\boxed{
\text{unique active solution}
\Rightarrow
\text{ordinary gradient}
}
]

否则：

[
\boxed{
\text{degenerate optimum}
\Rightarrow
\text{generalized/subgradient}.
}
]

工程上可以从最优 dual face 中选：

[
\text{minimum-norm dual/subgradient}
]

提高稳定性。

如果最后确实使用 entropy/proximal smoothing，则应该报告：

[
\varepsilon_{\rm reg}
]

并把它称为：

> smoothed capability gradient

而不是原始 (\gamma^\star) 的唯一梯度。

这会更严谨。

# 7. 真正能保证“单调下降”的不是梯度本身，而是 trust-region + verification

几何问题整体是非凸的。

所以即使：

[
g=\nabla_x\gamma^\star
]

正确，也不能说：

[
x-\alpha g
]

对任意步长都会降低 (\gamma^\star)。

严格可以说的是：

如果当前点可微且

[
g^Td<0,
]

则存在足够小的 (\alpha>0)，使：

[
\gamma^\star(x+\alpha d)
<
\gamma^\star(x).
]

所以 L3 应该做：

[
\boxed{
\min_{\Delta x}
\quad
g^T\Delta x
+
\frac{\kappa}{2}|\Delta x|^2
}
]

s.t.

[
|\Delta x_k|
\le r_k^{TR},
]

并包含：

- UAV 最大速度；
- 区域边界；
- UAV 安全间距；
- DD support margin；
- 必要 U2U connectivity / packet feasibility。

然后 candidate geometry 上**重新运行 L1 power/capability solver**。

接受条件：

[
\boxed{
\gamma_{\rm new}^\star
<
\gamma_{\rm old}^\star
}
]

更正式可用 Armijo 型：

[
\gamma_{\rm new}^\star
\le
\gamma_{\rm old}^\star
+
c\alpha g^Td,
\qquad0<c<1.
]

这样才有：

[
\boxed{\text{accepted geometry steps monotonically decrease actual capability deficit}}
]

而不是只保证 surrogate gradient 好看。

}

其中：

# [ r_{\rm kin}

来自运动学；

[

[

来自局部线性模型可信范围。

这样 trust region 也是物理产生的，不是扫描超参数。

# 9. L3 第一轮不要马上做 multi-step closed loop

我建议按照下面这个 Gate 顺序。

| Gate      | 做什么                                                  | 必须得到的结论                                   |
| --------- | ------------------------------------------------------- | ------------------------------------------------ |
| **L3-T1** | capability KKT sensitivity 推导                         | 得到完整 (\pi^\star)，而非复用旧 (\lambda^\star) |
| **L3-T2** | analytic gradient vs finite difference                  | 非 DD-crossing 状态下方向导数一致                |
| **L3-G1** | 12 个 hard 帧做 one-step trust-region                   | accepted step 的 (\gamma^\star) 必须严格下降     |
| **L3-G2** | 与 random / toward-worst-target / old Actor movement 比 | capability decrease 明显更高                     |
| **L3-G3** | 5–10 step receding-horizon                              | 看多少 (\gamma>1) hard state 被推到 (\gamma\le1) |
| **L3-C**  | 加 communication-gradient term                          | 验证 sensing-only 与 true ISAC geometry 的差异   |

尤其 L3-T2 非常重要。

例如随机取 admissible direction (d)，比较：

[
\frac{
\gamma^\star(x+hd)-\gamma^\star(x)
}{h}
]

与

[
g^Td.
]

随着

[
h\rightarrow0
]

在 active set 稳定、DD 不跨门时应该收敛。

这会成为你的**理论—代码一致性证据**。
