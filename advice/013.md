这版快照出来以后，优化方向已经和上一轮明显不同了：**8/8 不再是“怎么继续把性能做高”的问题，而是“怎么证明 0.975 真、解释 6/6 为什么崩、再把隐蔽性彻底分布式化”**。从你上传的总纲看，D1.1-A/B/D/E 已经把原来最大的算法缺口基本补上了。

我建议接下来收敛成三个阶段。

## 1. D1.5：先冻结算法，做最终盲测

现在 **0.975 暂时不要再优化**。

因为：

[
0.662
\xrightarrow{\text{lex L1}}
0.844
\xrightarrow{\text{multi-candidate L3}}
0.975
]

已经形成了非常漂亮的逐层因果链，而且是在同一 live 路径、同 warm-start 下得到的，不再是 oracle。

继续调参反而会产生 selection overfitting。

建议立即冻结一个候选：

[
\boxed{
\text{L0-KKT}
+\text{Lex-L1}
+\text{P0-L2}
+\text{Multi-candidate L3}
}
]

然后只允许：

- bug fix；
- 数值容差修复；
- 日志/manifest 修复；
- **禁止根据 blind seed 性能调整参数**。

最终盲测建议至少：

[
N=100,
]

更理想是：

[
N=200.
]

主判据不要再用 `mean worst ≥ 0.6`，而采用：

[
\hat p_{\rm QoS},\qquad
LCB_{95%}(\hat p_{\rm QoS}).
]

同时报告：

[
\text{mean/median/worst quantiles}
]

而不是只有均值。

### D1.5 最重要的不是证明“mean worst≈0.975”

而是验证：

[
\boxed{
P(\text{QoS feasible})\ \text{是否稳定地高}
}
]

如果 blind 100 seed 仍保持例如：

[
\hat p \ge 0.95,
]

那么 Wilson LCB 也会进入一个很有说服力的区间。

这时论文中的主结果才真正锁死。

# 2. 6/6 不要直接“专项训练”，先做一次失效机理分解

这里我会稍微修改你当前第②项。

现在直接说：

> 6/6 零样本失败 → 训练 6/6

还略快了一步。

因为 6/6 的

[
\text{worst}=0.29\sim0.34
]

不是轻微 domain gap，而是**灾难性下降**。

这么大的下降必须先回答：

[
\boxed{\text{到底是谁坏了？}}
]

建议做一个极小的 6/6 oracle waterfall：

[
\text{current 6/6}
]

→ 换 L1 lex

→ 换 L3 analytical

→ 换 structure oracle

→ 换 geometry oracle

→ relaxed physical ceiling。

也就是测：

[
W_0,\quad
W_{\rm L1},\quad
W_{\rm L1+L3},\quad
W_{\rm struct},\quad
W_{\rm geom},\quad
W_{\rm relax}.
]

最终把问题分成三种。

### 情况 A：解析 L1/L3 一上去，6/6 就恢复

那说明失败根本不是“跨尺度学习”。

而是：

[
\boxed{\text{旧 6/6 deployment configuration mismatch}}
]

这种情况下没必要重新训练 Student。

------

### 情况 B：结构 oracle 可以恢复，但当前 Student 不行

这才说明：

[
\boxed{\text{structure transfer failure}}
]

此时再做 6/6-specific / multiscale Student 是合理的。

训练目标就应该集中在：

- role；
- owner；
- support；
- cardinality；

而不是重新训练整个 actor。

------

### 情况 C：连 relaxed/current-geometry ceiling 都很低

那说明其实是：

[
\boxed{\text{geometry/physical feasibility shift}}
]

例如虽然面积按

[
L\propto\sqrt K
]

保持了节点密度，却不代表双基地有效覆盖、owner 可行域或最差目标几何统计保持不变。

这种情况下“专项训练”治不了根本问题。

------

## 因此 6/6 下一步最推荐的是

[
\boxed{\text{D1.6 Scale Failure Decomposition}}
]

而不是立刻 D1.6 Training。

这会让论文里“跨尺度失败”从一个尴尬负结果，变成一个很有价值的研究发现。

# 3. T3 的下一步才是真正剩余的算法创新

目前 T3 的 live power layer 已经很漂亮：

[
P_D^I\le\epsilon
]

可以逐帧满足，而且 weak → medium → strong 时任务性能单调下降，strong 时接近静默。

这已经证明物理逻辑基本正确。

现在最值得做的算法工作是：

# [ \boxed{ s_{iq}

## \lambda_q a_{iq}

\sum_w\mu_w a^I_{iwq}
}
]

真正接入有限轮 Dantzig–Wolfe。

这样现在的中央 LP：

[
\max t
]

s.t.

[
D_q\ge t,
]

[
D_w^I\le \bar D_w^I
]

可以转成分布式价格协调。

本地 UAV 只需要：

[
a_{iq},
\qquad
a^I_{iwq},
\qquad
\lambda_q,
\qquad
\mu_w.
]

然后解：

# [ q_i^*

\arg\max_q
\left[
\lambda_q a_{iq}
-\sum_w\mu_w a^I_{iwq}
\right].
]

这一步非常值得做，因为它不是“再提高 0.975”。

而是在解决论文最关键的结构性缺口：

> **隐蔽约束目前虽然 live，但优化仍是 centralized LP；完成 μ-price column generation 后，通信受限条件下的攻防资源协调才真正变成 distributed。**

这很可能成为最终论文最有辨识度的理论部分。

# 4. L2 暂时不要再优化

这一点现在应该明确冻结。

你已经得到：

那继续：

- 更复杂 owner search；
- N5/N6；
- combinatorial repair；

基本都属于低价值方向。

}

这是一个比“我们又设计了一个更强结构算法”更漂亮的 insight。

# 5. L3 也暂时不要再升级到复杂 MPC

上一轮我建议过 finite-horizon/trust-region。

但现在已有多候选 L3：

[
0.844\rightarrow0.975.
]

这个结果意味着现阶段没有理由立刻把它升级成 full MPC。

除非 D1.5 blind test 出现：

- 长尾 seed；
- 局部陷阱；
- 明显早期失败；
- high variance。

否则继续扩大 horizon 很可能只是增加计算量。

所以应该让证据决定是否升级：

[
\boxed{
\text{blind failure}
\Rightarrow
\text{再分析 L3 horizon};
}
]

而不是：

[
\text{0.975}
\Rightarrow
\text{继续复杂化}.
]
