**这个不修正，暂时不要正式宣称“只有 27.3% 功率层够”。**

# 2. 修正后，核心优化结构建议彻底改成两级

[
\max\text{-min}
\quad\text{vs}\quad

争谁是主目标。

改成：

[
\boxed{

\qquad
\textbf{Secondary: allocation quality}

------

## 一级：Capability Gauge

对任意任务参数

[
\xi=
(\rho_{\min},\rho_{\rm tail},\rho_{\rm avg},k)
]

定义任务集合

[
\mathcal A(\xi).
]

然后固定当前 geometry、structure、communication state：

# [ \boxed{ \gamma_P^\star(s,\xi)

\min_{\gamma,p}\gamma
}
]

s.t.

[
\mathbf D(p)\in\mathcal A(\xi),
]

[
\sum_qp_{iq}\le\gamma b_i,
]

[
p_{iq}\ge0.
]

这才是快层最核心的数学对象。

它回答：

[
\boxed{\text{当前控制自由度到底够不够？}}
]

不是“最差目标是多少”，也不是“bargaining value 是多少”。

------

## 二级：Constrained Bargaining

如果：

[
\gamma_P^\star\le1,
]

说明功率层本身足以完成任务。

此时才解：

[
\boxed{
\max_{p,\eta}\eta
}
]

s.t.

[
D_q\ge D_q^0+\eta h_q,
]

[
\mathbf D\in\mathcal A(\xi),
]

[
\sum_qp_{iq}\le b_i.
]

因此：

[
\boxed{
\gamma^\star=\text{能力判定},
\qquad
\eta^\star=\text{可行域内部的公平分配}.
}
]

这两个量不要再混。

这会比“同一个 bargaining value 贯穿三层”严谨得多。

# 3. D0.93-A2 值得做，但建议升级成“双侧 PWL capability certificate”

这一点可以成为很漂亮的理论贡献。

你现在计划只有：

[
\underline P_D(D)\le P_D(D)
]

的 chord 下界。

这可以保证：

> PWL 通过 ⇒ 真实 QoS 通过。

很好，但还有一个缺陷：

如果 PWL 判定“不够”，你不知道究竟是真的不够，还是下界太保守。

所以应该同时构造：

[
\boxed{
\underline f_M(D)
\le
P_D(D)
\le
\overline f_M(D)
}
]

其中：

- (\underline f_M)：凹函数 chord 插值，下界；
- (\overline f_M)：切线 envelope，上界。

对于凹函数：

- chord 在函数下方；
- tangent 在函数上方。

然后分别解两个 LP capability gauge：

# [ \gamma_L

\gamma^\star(\underline f_M),
]

# [ \gamma_U

\gamma^\star(\overline f_M).
]

因为下界问题更严格，上界问题更宽松，所以有：

[
\boxed{
\gamma_U
\le
\gamma_P^\star
\le
\gamma_L.
}
]

这比单独一个 conservative PWL 强很多。

# 4. 然后路由可以真正“认证化”

直接留下。

### 情况 B

对于你现在已经很高的 U2U bit/delay，这一点尤其重要。当前系统本身已经明确存在显著的协议通信成本以及严格 1 W 通感联合预算，因此避免不必要升级是物理上有意义的，而不只是计算优化。

# 5. PWL breakpoint 也不要均匀拍脑袋

这里可以再加一个正式误差界。

如果在区间 (I_m=[d_m,d_{m+1}]) 内

[
M_m=
\max_{D\in I_m}
|P_D''(D)|,
]

对于 chord 插值，有经典误差界：

[
\boxed{
0
\le
P_D(D)-\underline f_M(D)
\le
\frac{M_m}{8}
(d_{m+1}-d_m)^2.
}
]

所以如果希望每段误差：

[
\le\varepsilon,
]

只需满足：

[
\boxed{
\Delta d_m
\le
\sqrt{\frac{8\varepsilon}{M_m}}.
}
]

这意味着 breakpoint 应该：

- 高曲率区域密；
- 低曲率区域稀。

不是固定 8 段、16 段参数扫描。

这就符合你一直要求的：

> 参数选择来自理论，而不是经验拍值。

# 6. worst 约束甚至不需要 PWL

这是还能继续简化的地方。

因为 (P_D(D)) 单调：

[
P_D(D_q)\ge\rho_{\min}
]

可以**精确反解**成：

# [ \boxed{ D_q\ge d_{\rho_{\min}}

P_D^{-1}(\rho_{\min}).
}
]

所以：

- worst：精确线性 (D) 门；
- bottom-k：PWL；
- average：PWL。

这样保守误差只来自：

[
T_k,\quad A,
]

不会浪费在本来可以精确处理的 worst 上。

# 7. bottom-k 也不要继续枚举 ({Q\choose k})

8/8 时：

[
{8\choose3}=56
]

还没问题。

但你后面要做：

[
K\ne Q
]

甚至更大的 (Q)，组合数量会爆炸。

有一个更好的精确表示。

令 (y_q) 表示对应的检测概率下界。

(k) 个最小值之和满足：

# [ \boxed{ \sum_{j=1}^{k}y_{(j)}

\max_\tau
\left[
k\tau-
\sum_q(\tau-y_q)_+
\right].
}
]

因此

[
T_k\ge\rho_{\rm tail}
]

等价于存在 (\tau,z_q)：

[
z_q\ge\tau-y_q,
]

[
z_q\ge0,
]

[
\boxed{
k\tau-\sum_qz_q
\ge
k\rho_{\rm tail}.
}
]

PWL 情况下这些全是**线性约束**。

于是 bottom-k 复杂度从：

[
O\left({Q\choose k}\right)
]

降成：

[
\boxed{O(Q)}.
]

这个调整我强烈建议现在就做。

它直接让 D0.93-A2 从“8/8 专用模型”变成可以自然推广到任意 (Q) 的理论模型。

# 10. 但在结构层之前，我建议插入一个目前还没充分利用的“通信余量回收层”

这个点可能比继续调结构还有价值。

现在：

[
b_i=P_{\rm tot}-P_{{comm},i}.
]

Actor 仍然决定 (P_{\rm comm})。

那么对于：

[
\gamma_P>1
]

的帧，有两种完全不同的可能：

1. sensing geometry/structure 真不够；
2. Actor 给 communication 留了过多功率。

所以**不能看到 (\gamma>1) 就直接怪结构**。

如果当前 token set 和接收者固定，通信速率关于 (P_{\rm comm}) 单调，那么可以计算满足当前包送达要求的最小通信功率：

# [ R_i^{req}

\frac{L_i}
{T_{\rm deadline}-T_{\rm proc}},
]

对应：

# [ \Gamma_i^{rate}

2^{R_i^{req}/B_i}-1.
]

结合最低 SNR：

# [ \Gamma_i^{req}

\max
{
\Gamma_i^{rate},
\Gamma_i^{th}
}.
]

对于必须送达的 receiver set (\mathcal R_i)：

# [ \boxed{ P_{{comm},i}^{min}

\max_{j\in\mathcal R_i}
\frac{
\Gamma_i^{req}N_jB_i
}{
g_{ij}
}.
}
]

然后：

# [ b_i^{max}

1-
P_{{comm},i}^{min}.
]

实际代码如果还有 Rician、deadline、packet model，就直接对**真实单调通信核做数值逆映射**，不必硬套这个简化公式。

这一层的原则是：

[
\boxed{
\text{先保证现有通信语义不变}
\rightarrow
\text{回收多余通信功率}
\rightarrow
\text{再判断 sensing capability}.
}
]

这才是真正的 ISAC 联合资源原则。

否则我们的 analytical sensing solver 很强，但通信功率还是 Actor 随便给的，仍然是半解析、半学习。
