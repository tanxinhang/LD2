## 1. 第一关不是梯度，而是 **(\pi^\star) 到底怎么产生**

这是目前最关键的隐藏问题。

你说：

> 唯一全局信号是 (Q) 维 (\pi^\star)，广播给所有 UAV。

这本身没问题，但**如果 (\pi^\star) 是由某个节点收集完整 (A) 后求全局 capability problem 得到的，那么只是把中央规划器缩成了“中央价格计算器”**。

而且当前文档里的 DW 实际描述是：

> owner 广播量化价格，各 UAV 本地生成列，**owner 端求 (Q) 维 restricted master problem**。

所以它严格来说是：

[
\text{distributed local response}
+
\text{logical master/owner coordinator},
]

不是完全 coordinator-free。

因此 L3-T0 必须先固定二选一：

### 方案 A：允许 UAV 内部轻量 coordinator

没有外部中心站，但某个 owner/leader 汇总实际送达列并求 (Q) 维 master。

那论文应诚实写：

> distributed execution with lightweight in-network price coordination.

不能写“无任何中心协调器”。

### 方案 B：真正 coordinator-free

把 capability dual 写成 peer-to-peer dual update / consensus：

# [ \pi^{(r+1)}_k

\Pi_{\Pi}
\left[
\sum_{\ell\in\mathcal N_k}
W_{k\ell}\pi_\ell^{(r)}
+
\alpha_r,g_k^{(r)}
\right],
]

每架 UAV 只利用本地贡献和已送达邻居价格，最终形成近似公共价格

[
\hat\pi_k\simeq\pi^\star.
]

如果“没有中心协调器”是硬约束，我建议走 **B**。

这是 L3 理论 Gate 的第一项，不解决它，就还不能宣称 fully distributed。

[

[

**只在已有有效 support 的 smooth region 中成立。**

对于你刚发现的那些真正 geometry-limited hard states，这个问题可能恰恰非常严重。

# 6. 因此 L3 应该明确分成两个 mode

### Mode I：Capability descent

如果目标已有有效 support，并且距离 DD boundary 有足够 margin：

[
g_{dd}-g_{\min}>\delta,
]

使用：

[
d_k=-g_k.
]

这是对 (\gamma^\star) 的局部下降。

------

### Mode II：Support restoration

如果高价格目标 (q)：

[
\pi_q>0
]

但没有有效 sensing support，则不要继续算零梯度。

定义一个由物理约束违例直接产生的恢复势：

# [ \boxed{ \Psi_k

\sum_q
\pi_q
[g_{\min}-g_{dd,kq}]_+
}
]

或更完整地包括当前可达性的 delay/Doppler margin。

然后：

# [ d_k^{restore}

-\nabla_{x_k}\Psi_k.
]

其含义不是“优化性能”，而是：

> **先把高价值目标重新送回 sensing feasible manifold。**

一旦跨回：

[
g_{dd}\ge g_{\min},
]

立即：

1. 重建 support；
2. 重求 capability/power；
3. 更新 (\pi)；
4. 回到 Mode I。

这会让 L3 对 hard geometry 真正有用，而不是只在 easy smooth states 上工作。
