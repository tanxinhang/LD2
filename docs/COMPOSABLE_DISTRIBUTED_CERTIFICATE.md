# 目标级可组合分布式证书（v1）

## 1. 证书对象

v1 证书只证明“已经执行的联合功率矩阵”的保守性能，不把不同私有信息集上的局部
LP 最优值相加，也不宣称联合方案达到全局最优。对固定结构，真实目标偏转量写成

\[
D_q(p)=\sum_{k=1}^{K} a^{\rm true}_{kq}p_{kq},\qquad
p_{kq}\ge 0,\quad \sum_qp_{kq}\le b_k.
\]

执行节点 \(k\) 从自己的物理可得状态和不确定集构造行下界
\(\underline a^{(k)}_{kq}\le a^{\rm true}_{kq}\)，随后形成

\[
\underline c_{kq}=\underline a^{(k)}_{kq}p_{kq}.
\]

目标 \(q\) 的责任节点固定为 \(o(q)=q\bmod K\)。责任节点收到同一源帧的全部 K
个行报告后只做加法：

\[
\underline D_q=\sum_k\underline c_{kq}\le D_q(p).
\]

检测概率关于偏转量单调，因此
\(P_D(\underline D_q)\le P_D(D_q)\)。这一步不要求各节点拥有相同视图，也不要求
它们的局部 LP 解彼此一致，因而具有可组合性。

## 2. 物理下界

路径增益按最坏距离端点计算。连续 OTFS DD 增益使用位置和速度不确定集：双基地
时延对两个端点和目标位置满足三角不等式；多普勒方向误差采用

\[
\|\Delta u\|\le \min\left(2,\frac{2r}{R-r}\right).
\]

由此得到时延/多普勒的分数栅格区间，在区间上计算
\(|\operatorname{sinc}(x-\operatorname{round}x)|\) 的最小值。只要整个区间位于
OTFS 支撑内，才保留正下界；否则该边下界置零。当前严格配置使用 8 bit 端点状态
量化误差和局部跟踪协方差的 3σ 椭球。因高斯误差本身无界，证书是“真实状态位于
声明不确定集”条件下的确定性保证；它不是未经校准的无条件概率保证。

## 3. 量化、完整性与通信

每个 \(\underline c_{kq}\) 使用 16 bit 对数量化并始终向下取整；超量程饱和值仍不
大于原值，小于首个正网格的量解码为零。v1 同时采用公共均匀目标价格
\(\pi_q=1/Q\)。节点 k 从不确定集系数上界构造一个向上量化的行对偶项

\[
u_k=b_k\max_q \pi_q\overline a_{kq},\qquad
t^\star\le U=\sum_k u_k.
\]

上界量化若超量程会拒绝运行，绝不饱和成无效“上界”。由此得到条件联合近似保证
\(\min_q\underline D_q/U\)。每个发送者还携带 32 bit 源帧号。严格
K=Q=8 配置的证书负载为

\[
(8+1)\times16+32=176\ \text{bit/sender/carrier}.
\]

这些比特通过现有 U2U 物理传输模型计费，参与包序列化时延、截止时间、投递、能耗
和丢包判定。责任节点只有在以下条件全部满足时出证：

1. K 个发送者的报告均已物理投递；
2. K 个报告源帧完全一致；
3. AoI 不超过配置阈值；
4. 目标由确定性责任映射唯一负责。

任一条件失败时，该目标证书下界归零，不能用 \(P_{FA}\) 冒充感知成功。

## 4. v1 明确不证明的内容

- 不证明拼接功率是任何共同信息集下的全局最优解；
- 现有均匀价格上界通常很松；它证明固定结构的条件近似比，但不证明跨结构全局最优；
- 不将 3σ 条件保证描述成 100% 统计置信保证；
- 不允许用仿真真值生成在线报告；真值仅可在离线审计中检查覆盖率；
- 证书较低不等于实际性能必然较低，它可能只是跟踪不确定集或 DD 区间过宽。

下一理论阶段不应增加新模型，而应收紧公共价格：在不泄漏私有完整增益图的条件下，
通过有限轮公共 simplex 价格 \(\pi\in\Delta_Q\) 最小化
\(U(\pi)=\sum_k b_k\max_q\pi_q\overline a_{kq}\)。均匀价格已经保证有效，后续优化
只允许降低上界，不能改变已执行功率或破坏证书方向。

2026-08-28 的 12 帧 seed=7 冒烟（仅工程检查）中，carrier period=1 时证书完整率
为 11/12（首帧没有可认证的既有功率），负载 176 bit/sender/carrier；稳健
Worst \(P_D\) 下界约 0.007，固定结构均匀价格近似比下界约
\(2.83\times10^{-4}\)。数值非常保守，却是方向正确的全局条件证书；它诚实暴露
跟踪/DD 不确定性和均匀对偶价格的松弛，而不是把局部 LP 值包装成全局保证。

## 6. K16/Q16左尾诊断与被否决方案

2026-08-28在seed 7、150帧的同帧安全增益上增加了默认关闭的共同信息集影子LP。
该LP只测量“若安全行能够组合，物理上最多可达到什么”，不参与执行，也不得计入
候选时延。影子最优 \(P_D\) 下界均值为0.934、P05为0.632，95.3%的帧达到0.6；
这说明大多数低谷不是感知几何本身不可行，而是私有LP行拼接失配。

以下方案经过影子测试后被否决：

- 固定稀疏调和分配的平均偏转近似比仅约0.238；
- 镜像价格下降从1轮增加到32轮仍停在相同解，通信增加但无性能收益；
- 每3帧更新并保持功率的方案在10个开发种子中出现进入Service后的再次失效；
- 即使使用不可实现的未来3帧逐元素最小增益，有限轮求解与结构切换仍会造成失效。

Dantzig--Wolfe列生成在seed 7上从1/2/4/8轮的平均偏转比分别约为
0.529/0.611/0.811/0.922，但多轮价格—反馈消息和顺序依赖不能免费忽略。保守的
所有者路由至少需要初始安全行汇聚、每轮目标ID/贡献反馈、目标汇聚和价格广播；在
物理DAG、bit和AoI全部接入前，它只能是影子上界，不能替代当前严格分布式执行。

10个开发种子的“共同信息LP连续3帧达到0.6”采集时刻分布为5--48帧，且在60帧
诊断窗内此后没有再次失效。这支持未来采用显式Acquisition/Service状态机，但不能
固定删除前N帧；切换必须由当前可组合下界因果触发，采集时长也必须单独报告。
