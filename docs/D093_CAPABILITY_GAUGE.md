## 1. 两处修正（advice 003 的批评）

1. **D0.93-R 的"0.66 功率层够"是错的**：它只验了 worst+steady、漏了 bottom-3，且
   随 `w` 升高不可行帧被删除（survivorship bias），使 mean steady 反而上升——违反
   `S*(w2)≤S*(w1)` 的基本单调性。那不是 Pareto frontier。
2. **正式 QoS 是三项**：`W≥0.60, T_3≥0.70, S≥0.80`。D0.93-R 只验了两项。

## 2. Capability Gauge（advice 003 §8 的干净证书）

```text
γ_P* = min_{p,γ} γ
s.t.  D_q = Σ_i a_iq p_iq
      W(D)≥ρ_min, T_k(D)≥ρ_tail, A(D)≥ρ_avg      （完整任务集）
      Σ_q p_iq ≤ γ·b_i,  p≥0
```

`γ_P* ≤ 1 ⟺ 功率层单独可完成完整任务`；`γ_P* − 1` 是固定结构还需的等效额外感知预算
比例。`γ>1` 只是诊断变量，实际执行仍严格 1 W。

## 3b. 一致性修正（advice 004 §1 的 bug）

`27.3%` 与 `median γ=0.696` 的矛盾是**分母口径不一致**：中位数只在 **152 个可解帧**
上算，而 27.3% 用 450 做分母。正确分解是：

1. **~66%（298/450）帧是结构瓶颈**：至少一个目标在固定结构下 ceiling < d_0.60
   （该目标在任何功率分配下都到不了 0.60）→ 功率层**无法尝试**，需结构层。
2. **~34%（152/450）帧可解**，其中 **81% 可行**（γ≤1，中位 0.696）。
3. 用 O(Q) order-statistic 表示后 bottom-3 约束违例 ~1e-8（精确）。

**结论修正**：不是"功率层只够 27%"，而是"**功率层对可解帧通常够（81%），但 66% 的
帧根本是结构瓶颈**"。这比之前的表述精确得多。

## 4. 判定（修正后）

1. **结构瓶颈占比 ~66%，不是功率瓶颈**：298/450 帧里某目标在固定结构下到不了
   0.60（ceiling < d_0.60）。这才是真正需要结构层的部分。
2. **可解帧里功率层通常够（81%）**：中位 γ=0.696，一半可解帧有 ~30% 余量。
3. **γ_P* 是结构层的正确触发强度**：`G_P=(γ_P*−1)_+` 归一化、跨规模可比，替代
   `η*≤0`；对不可行帧给出"差多少"（γ−1）而非只报 infeasible。

## 5. 理论点：bottom-k 不破坏凸性（Proposition）

```text
T_k(D) ≥ ρ_tail  ⟺  (1/k)Σ_{q∈S} f_q(D_q) ≥ ρ_tail   ∀|S|=k
```

每个子集的 `Σ f_q(D_q)` 是凹函数之和（凹），其 superlevel set 凸；`C(Q,k)` 个凸集
之交仍凸。故 `W, T_k, A` 三个 QoS 约束**同时进入凸可行域**（`f_q=P_D` 在 `D≥d_0.60`
区域凹）。所以 D0.93-A 是**凸规划**（Slater 下强对偶/KKT），不是 SLSQP heuristic。
