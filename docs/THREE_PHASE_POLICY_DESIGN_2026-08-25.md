# 三段式分布式 ISAC 策略设计（2026-08-25，理论推导）

目标：针对深度审计确认的两大根因——(R1) 局部视图不一致导致"目标漏追"、
(R2) 航程恰好处于 P_D=0.6 临界无裕量——设计三段式策略：前期快速收敛
(Phase A)、后期补强+兜底 (Phase B)、近场通信-感知-位置联合调整 (Phase C)。
所有规则确定性、纯本地视图可算、无全局真值/证书交换。

## 物理基础（参数取自冻结 config）

- 双基地 per-watt 增益 `a_ijq ∝ α² / (R_iq² R_jq²)`，P_D = Φ(Φ⁻¹(P_FA) − √D)，
  D = c_det·(P·a·G_ant/σ²)·MN·n_CPI。
- 理论临界半径（对称双基地、单 Tx 全功率 25.1 mW）：
  P_D(R=300 m)=0.99，P_D(350 m)=0.81，P_D(400 m)=0.47，P_D(478 m)=0.17。
  实测含 DD gate / 量化 / 功率分配损失后，P_D=0.6 的实际临界半径
  **R_crit ≈ 280–320 m**（实测：286 m→0.515，271 m→0.558，758 m→0.011）。
  取工程值 R_crit = 320 m（可配置），对应"进入临界带"的定义。
- 最大航程 v_max·dt·T = 2.5 m/帧 × 150 = 375 m。
- 通信：FBL、4 ms deadline、每帧证据+belief 比特预算；感知功率每 UAV
  上限 P_sense_max = 25.1 mW；总 ISAC 功率 1 W。

## Phase A：前期远场快速收敛（gap-minimizing 覆盖 + 全速追击 + 兜底）

**覆盖不变式**（不变式 C1）：

    ∀ q, ∃ i ∈ Tx, j ∈ Rx : ‖x_i − z_q‖ ≤ R_crit 且 ‖x_j − z_q‖ ≤ R_crit.

满足 C1 时每目标至少存在一个临界半径内的 Tx–Rx 对。C1 不满足的目标
集合 U = {q : 缺口}。**收敛速度定义**：目标 q 的收敛帧数
T_q = ⌈(R_q(0) − R_crit)/2.5⌉；前期目标是 min 瓶颈 max_q T_q。

**缺口优先追击规则**（乘积序，2026-08-25 修正）：UAV k 在其责任集
𝒦_k（≤2 目标）中选择

    q_k(t) = argmax_{q ∈ 𝒦_k} R_kq² · (min_{j ∈ opp(k)} R_jq)²

即以"自身到目标距离平方 × 异角色最近端点距离平方"的双基地瓶颈乘积最大
者为追击目标（全速 2.5 m/帧、直线，直到 standoff 钳制）。
理由：P_D 关于 −(R_tx²·R_rx²) 单调（双基地 1/R⁴ 增益），追乘积最大者是对
P_D 门瓶颈的最陡下降；与早期"gap = max(0, R − R_crit)"版本的区别是
**不因目标进入临界半径而停止**（gap 序在 R ≤ R_crit 时 near_hold，导致
目标停在临界边缘、P_D 停在 ~0.1–0.5，且只追单端点）；乘积序持续逼近
直到安全 standoff，使 Tx 与 Rx 两端点都被各自责任 UAV 持续接近。

**近场聚焦（Phase B 补强，2026-08-25 第二轮）**：25-seed v1 的 4 个未过门
种子中有 2 个"距离已近但 P_D 未达标"（647973436: 278 m→0.589、
1466409252: 289 m→0.582）——近端端点已进入临界带，但乘积序可能把近端
责任 UAV 拉去追"更差的另一责任"，使近端停在原地、对侧远端（450–500 m）
拖累乘积。判定（公共视图可算）：目标近端 ≤ 300 m 且远端 > 350 m 即
critical；其**两个责任端点都被强制追该目标**（忽略乘积序），直到远端
也进入完成半径。理论：P_D 瓶颈乘积 R_near²R_far² 的梯度
∂/∂R ∝ −4/R⁵·(对侧)²，近端 278→200 m 使乘积降 33%，是当前几何下最快的
P_D 提升方向；聚焦防止近端被其他责任稀释。

**兜底重分配**（C1 维持，修复根因 R1）：每帧（公共视图 complete 时）
计算 U；对 q ∈ U 按确定性顺序（目标 ID 升序；同目标按端点距离升序、
端点 ID 升序）指派最近的、当前责任数 < capacity 的**异角色**端点补位。
角色取"缺口侧"：q 缺 Tx 则补 Tx，缺 Rx 则补 Rx，两侧都缺先补 Tx。
所有 viewer 用同一公共视图 + 同一规则 → 补偿结果一致 → 无拼接歧义。
与现有固定 hold 的区别：hold 期间仍监控 C1，出现缺口立即补偿，
不再等 150 帧。

**一致性论证**：分配只依赖 (i) 公共端点位置（offers）、(ii) 公共角色
划分、(iii) 公共目标 belief——三者都是确定性可重建的公共量；补偿规则
是纯函数，无随机性、无全局质量向量，因此一致率由视图一致性决定，
而视图一致性已由 hybrid freshness（belief RMSE ≤ 12 m）与
budget-reconstructable offers 保障。

## Phase B：后期临界带补强与兜底（P_D 分档）

**分档**（本地 P_D 可算）：critical = P_D ∈ [0.40, 0.60)，
near = [0.60, 0.80)，saturated = [0.80, 1]；dead = P_D < 0.40。

**max-min 单调性引理**：D_q 关于 (P_q, 1/R_txq²R_rxq²) 单调增，P_D 是 D_q
的单调增函数；在 P_D ∈ [0.8, 1] 饱和区，∂P_D/∂P_q ≈ 0（P_D 的凹饱和）。
因此把饱和目标的感知功率/端点资源让给 critical 目标，在 max-min 意义下
单调不减（饱和方损失 ≈ 0，临界方增益 > 0）。

**端点补强**：critical 目标获得第二端点（结构补强：同一目标两个 Tx 或
两个 Rx 端点都进入临界带）；near 目标保持单端点；saturated 目标的端点
释放（允许被兜底/补强调用）。dead 目标进入 Phase A 兜底（U）。

**实现落点**：运动层（responsibility 分配给 critical/dead 目标多一个
端点）+ 功率层（P0 LP 已按 max-min 分配，配合释放即可）。

## Phase C：近场通信-感知-位置联合调整

**近场定义**：目标 q 的所有责任端点已进入 [R_standoff, R_crit]。

**几何自由度**：径向已由 Phase A/B 完成，近场只剩切向（角度）自由度。
固定 R_tx、R_rx 时双基地增益不变，但 delay-Doppler 支持
(τ, ν) 随角度变化；DD gate g_dd ∈ {0,1} 决定系数是否可用。因此近场
位置目标函数：

    maximize  Σ_q  [ w_dd · g_dd(τ_q, ν_q) + w_g · (1/R_txq²R_rxq²) ]
    s.t.      R_kq ≥ R_standoff（安全，不变量 S1），R_kq ≤ R_crit（不掉出）

**切向步**：在半径保持（不变量 S1 维持，严格不减少 R_kq − R_standoff）
的切向上，用 Gauss–Southwell 单坐标规则选择使 log 增益改善最大的
UAV–目标切向步（复用 sweep 结构，θ 方向确定性 tie-break）。

**通信-感知协同**：
- 感知功率向 critical 目标集中（P0 已支持，配合 Phase B 释放）。
- belief/证据通信预算按目标分档倾斜：critical/dead 目标的 belief
  top-up 优先（freshness 调度已按 AoI/不确定性/任务亏损打分——把
  "任务亏损"分量替换/加权为"P_D 分档亏损"，即 1 − P_D_q 的单调代理，
  理论：belief 新鲜度 → 2-sigma 鲁棒增益去保守化 → 有效增益提高，
  与 Phase A 的 gap 收敛正交叠加）。
- 近场目标证据更值钱（P_D 高、LLR 信噪比高）：证据 top-k 保持。

## 创新点小结

1. **gap-minimizing 收敛**：以"到临界半径的剩余路程"为追击序（对准
   P_D≥0.6 门），区别于 max-range 或 max-deflection 序。
2. **C1 覆盖不变式兜底**：固定 hold 期间的缺口监控 + 确定性补位，
   直接修复"漏追"根因（role-capacity 已验证一致率 0.93 → P_D 33×）。
3. **P_D 分档资源释放-补强**：饱和区 ∂P_D/∂P ≈ 0 的单调性引理。
4. **近场切向 DD-gate 优化**：径向完成后用切向自由度改善 DD 支持，
   保持安全距离不变量（S1）——现有系统只有径向 + 固定 standoff。
