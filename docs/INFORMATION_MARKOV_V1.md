# 信息状态驱动的 ISAC 联合决策：实验版本 IM-v1

状态：框架与有限状态参考求解器已建立；主线为无ACK、无重传的单次局部似然消息与历史融合。
完整感知—通信联合动作策略尚未闭合。
此文档固定实验定义，不是 Git release 或性能认证。

## P0 扩展：历史条件信息驱动的主动几何

下一生存门冻结 OTFS numerology、pilot 和 RF 功率，只开放有限单步机动原语与单 Tx、多 Rx
半双工角色集。几何、角色、DD signature 和杂波协方差不通过人工权重相加，而进入联合观测模型：

\[
\Delta D(a\mid H)=(\delta_a-C_{aH}C_{HH}^{+}\delta_H)^H
(C_{aa}-C_{aH}C_{HH}^{+}C_{Ha})^{+}
(\delta_a-C_{aH}C_{HH}^{+}\delta_H).
\]

该量是等协方差高斯模型下的条件 Deflection（高斯 KL 的两倍），不是检测概率。联合协方差
非半正定、或均值落在协方差支撑空间外时 fail closed。代理量只用于筛选，最终执行候选必须经过
Top-M frozen OTFS 精确复算；研究结论仍由相同固定虚警率下的独立 held-out 检测比较决定。

若本帧没有消息发送，不预留也不消耗通信功率。推进能耗与每节点 1 W RF 上限分别核算。
几何消融存活前不开放自适应通信/感知功率或波形优化，以免把功率收益误记为机动收益。

## 目标与约束

在声明的任务窗口 T 内最大化检测性能。单目标目标为 P_D(T)；多目标目标为 min_q P_D,q(T)。
P_D>0.8 是验收条件，不是达到后自动停止优化的饱和目标。固定虚警设计点 alpha=0.001；
扫描多个目标或采用序贯停止时，必须定义并校准整体虚警事件。

每节点 P_sense+P_comm<=1 W。时长、空口、收发角色和计算限制作为可行域；不使用人工加权
能量/bit/计算惩罚构造主奖励。800 m 当前指两条双基地传播腿各800 m。仅共享1 W的新硬件假设
与旧25.1 mW感知上限分别标识。历史旧门槛0.2不用于此版本验收。

## 信息状态、动作与更新

节点状态包括目标/环境的信念、尚未发送的源证据、已收到的证据身份、相关性估计、
时钟和剩余资源。传入状态的信息必须来自本地观测或已送达消息；完整全局后验不能假装为
本地可用状态。现有信息状态列表是设计要求，尚未证明有限维Markov充分性。

动作包括感知/通信功率、波形或照射选择、消息内容和量化。融合是同一状态的更新：去重、
目标关联、运动对齐、时空相关性建模都属于观测似然；不得把由历史估计的轨迹再视作独立证据。
互信息和条件Deflection只能作为经验证的计算近似，不能无证明替代固定虚警下的P_D目标。

有限单目标参考模型使用终端奖励 g(s)=P_D(s;alpha)，反向递推
V_h(s)=max_{a feasible} sum_{s'} P(s'|s,a)V_{h-1}(s')，V_0=g。
实现为 physical/information_markov.py，逐节点检查功率预算。转移中必须包含观测、消息失败、
历史更新和资源消耗；测试使用合成转移只证明递推正确，不声称来自物理系统。
多目标 min_q E[P_D,q] 不能简单改成 E[min_q P_D,q]；多目标需独立约束/向量价值推导。

加速可以缓存相同状态转移和复用历史增量，但近似剪枝需记录价值误差。当前参考实现为稠密
有限状态DP，尚无连续动作、分布式近似或在线实时性保证。

## 已有证据及推进门禁

1. 底座：真实模拟FBL路由→owner历史→检测已接通，见audit_link_history_detection.py。
   该底座使用固定功率，不属于IM-v1策略。三节点8块实验平均P_D可超过0.8，但链路尾部失败。
2. 参考求解：验证两步动作能发现“先获取再发送”的终端价值，且拒绝超过1 W的动作。
3. 下一步：从底座产生具有可用信息约束的动作转移；校准与评估使用不同随机种子，比较相同
   模型/预算/截止时间下的固定策略、当前状态策略和历史信息策略。
4. 通过条件：检测置信下界>0.8、虚警门禁、逐节点预算与截止时间同时满足。新策略优越性另需
   配对统计；对有限链路银行的条件置信结论不能升级为随机环境保证。

没有完成步骤3之前，不报告IM-v1检测性能或创新收益。

## 当前无ACK路径（C19）

每块remote Rx只发送该块新观测对固定位置假设格点的log-likelihood ratio（五个float32）。
不是发送包含旧历史的后验。接收端先预测其H1信息状态，再乘本地似然和实际收到的远端似然；
丢包项为1，旧消息不重传。H0也按同一含丢包机制校准。日志域总质量是检测log LR，归一化后
才是H1条件位置后验；归一化时不能丢掉检测证据强度。

第一轮使用静止未知目标（单位Markov转移）、真实位置格点对应的双基地OTFS模板、未知独立相位
精确边缘似然。这样避免把毫秒内几十米格点跳变伪装成合理运动。跨节点杂波相关性未建模，
有共同杂波时不能继续无条件相乘似然。

脚本audit_noack_markov_fusion.py中calibration H0、validation H0/H1各100000样本，使用不同
链路和噪声种子。8块统一融合P_D点估计0.80083，但条件置信下界低于0.8；不得宣布达标。
此阶段检验通信辅助目标状态估计及历史检测，尚未实现基于后验的波形/功率动作变化，也没有
用目标感知人为提高U2U通信增益。两个方向的物理因果模型仍需分别验证。
