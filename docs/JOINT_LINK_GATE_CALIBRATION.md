# Observable link prediction and policy/threshold fixed-point experiment

## Boundaries

Sensing power and physical scenario are unchanged. This is an opt-in audit,
not a deployed controller, a power optimizer, or guaranteed joint optimization.
The receiver sees scheduled packet arrival/absence in the prefix, not hidden
CSI or future actual deliveries. There are no ACKs or retransmissions.

## Link model

Fit an observed two-state delivery Markov chain using 80 independent simulated
radio traces (seeds 820000..820079), each 13 frames with the existing control
slot. Add one pseudocount per transition cell. Test on 80 separate traces
(830000..830079). The learned transition matrix, ordered failure/success, is:

    [[0.57707510, 0.42292490],
     [0.14908579, 0.85091421]]

Held-out one-step Brier score is 0.15737946 vs 0.19605497 for the fitted iid
baseline. Lower is better. This is descriptive held-out improvement, not a
confidence-certified population claim. Forecast rollouts start from the last
received-slot outcome and evolve without future actual masks. The full prefix
still updates the target-state evidence posterior.

An observed binary Markov chain is only an approximation to continuous hidden
correlated shadowing. It retains last-outcome dependence, not all history;
parameter uncertainty and lag-dependent calibration remain untested. All traces
share the frozen geometry. Pooling transitions across the control slot also
approximates its timing effect. Do not claim physical channel identification.

## Policy and threshold

With fixed rollout draws and link predictor, map design threshold h to the
H0 99.95th percentile of the adaptive policy using h. Iterate at most four
times. Design uses 10,000 H0 samples, seed 750001; H1 outputs generated by the
audit are not used to select the threshold. Iterations were:

    4.322597843473792 -> 5.638429914577316
    5.638429914577316 -> 5.638429914577316

This demonstrates an empirical fixed point for this sample, not uniqueness,
optimality or population calibration. Only about five design observations
populate the nominal upper tail, so substantial threshold sampling error is
expected. Forecast and final gate thresholds are then frozen to the SAME
5.638429914577316. Independent validation must accept or reject that pair;
its threshold is never silently recalibrated on validation data.

The implementation also uses separate nested random streams for Markov paths
and complex observation noise so that increasing rollout count preserves
previous draws in the Markov variant. This removes the previous non-nested
sensitivity comparison but does not by itself bound Monte Carlo decision error.

Run `python -m tools.audit_joint_link_gate` to reproduce fitting, design and
100,000-per-split validation (trial seed 760001, link seed 650000, 64 rollouts).
The full-report reference keeps its usual separate H0 calibration. Pairwise
intervals are conditional on both frozen thresholds and channel, not uncertainty
over training/calibration or geometry. No claim of speedup is made.

## Frozen validation result: reject candidate

| Metric | Full reference | Frozen gate |
|---|---:|---:|
| PD | 0.85876 | 0.79801 |
| PFA | 0.00039 | 0.00009 |
| Threshold | 4.44792653 | 5.63842991 |
| H1 mean bits | 1664 | 1712.94976 |
| H0 mean bits | 1664 | 1746.33472 |

Gate PD interval [0.79414743,0.80183419], PFA interval
[0.0000253410,0.000222984]. PD > 0.8 is not demonstrated and its point
estimate fails. Paired delta -0.06075, conditional conservative 95% interval
[-0.06250638,-0.05898523]. Full-only detections 6081, gate-only 6.
H1 stop fraction 6.862% remains below communication break-even; no improvement.

The much lower achieved PFA and higher frozen threshold are consistent with
overconservative small-sample tail calibration, but this experiment does not
isolate that cause from adaptive gating. Empirical fixed-point consistency is
NOT sufficient statistical calibration. Do not lower the threshold after seeing
these H1 results and call the same split an independent validation. A subsequent
attempt needs substantially larger independent H0 design/calibration samples,
fixed rollout convergence checks, and fresh held-out H0/H1 tests. The learned
link predictor's Brier improvement alone cannot justify promoting this gate.
